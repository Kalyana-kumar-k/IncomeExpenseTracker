# SpendWise — Personal Income & Expense Tracker 📊

A lightweight, responsive web application to track personal cash flow, and monitor balances in real time. Built with vanilla HTML5, CSS3, and JavaScript, featuring persistent client-side storage via the browser's `localStorage` API.

---

## 🚀 Live Demo & Links

- **Live Demo:** [https://income-expense-tracker-ashen.vercel.app/]
- **Source Code:** [https://github.com/Kalyana-kumar-k/IncomeExpenseTracker]

---

## ✨ Features

- **Dynamic Financial Overview:** Real-time updates for Total Balance, Total Income, and Total Expenses.
- **Detailed Transaction Entry:**
  - Description and custom numerical amounts.
  - Transaction type toggle (Income vs. Expense).
- **Offline Persistence (`localStorage`):** Transactions and state are saved locally on the user's device—no external database or backend required.
- **Responsive Layout:** Optimized using CSS `@media screen` queries for seamless usability across mobile phones, tablets, and desktop displays.

---

## 🛠️ Built With

- **HTML5:** Semantic document markup and form controls.
- **CSS3:** Flexbox, CSS Grid, custom color variables, and `@media screen` breakpoints for responsive layouts.
- **JavaScript (ES6+):** DOM manipulation, state calculations, array filters/reducers, map and `window.localStorage` synchronization.
